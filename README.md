# 球场记分台

这是一个无需后端即可运行的篮球比赛记分网页，入口文件是 `index.html`。

## 让朋友使用

### 临时局域网访问

你和朋友连接同一个 Wi-Fi 时，可以把下面这种地址发给朋友：

```text
http://你的电脑局域网IP:4173
```

例如本机当前检测到的局域网地址是 `10.13.102.22`，朋友可以尝试打开：

```text
http://10.13.102.22:4173
```

电脑需要保持本地预览服务运行，并允许防火墙放行 4173 端口。

### 发布到公网

把整个文件夹上传到任意静态网站托管服务即可，不需要构建步骤。上传后朋友通过平台生成的网址访问：

- Netlify：直接拖入 `basketball-scoreboard` 文件夹
- Vercel：导入项目后选择静态项目
- GitHub Pages：将这三个网页文件放进仓库并开启 Pages

## 数据说明

当前版本的数据保存在浏览器本地。你和朋友打开同一个网址后，各自会有独立的比分记录。

如果需要你和朋友同时看到同一场比赛、实时同步比分，还需要增加云端数据库和实时通信服务。
